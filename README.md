# Saturday Night, Third Floor: Harlem, June 1926

A classroom game about Harlem in the week of 23–27 June 1926. Play it in Chrome at this repository's GitHub Pages address.

Press F9 in the game to report a problem; outside claude.ai the report is saved as a file you can hand to your teacher.
